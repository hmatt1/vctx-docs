## Why vctx?

vctx is a Hardware Description Language (HDL) designed with modern language features and a fast development lifecycle.

<CardGrid stagger>
<Card title="Explicit Timing" icon="seti:clock">
Clear distinction between combinational and sequential logic.
`:=` for wires.
`<=` for clocked updates.
</Card>
<Card title="Easy Simulations" icon="approve-check-circle">
Run simulations just like unit tests.
</Card>
<Card title="Strongly Typed Bit Widths" icon="puzzle">
The compiler natively tracks bit widths. Operations like `u8 + u8` automatically expand to `u9` to prevent implicit truncation.
</Card>
<Card title="Built on CIRCT" icon="rocket">
Leverages the power of LLVM and MLIR via the CIRCT project. Compiles to clean SystemVerilog for synthesis.
</Card>
<Card title="Formal Verification" icon="magnifier">
First-class support for formal methods. Use `sym`, `assume`, and `assert` to prove correctness.
</Card>
</CardGrid>
